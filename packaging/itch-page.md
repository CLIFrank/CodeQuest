# CodeQuest itch.io page copy

## Short description

Learn Python by solving story-driven coding missions in a playful desktop app.

## About CodeQuest

CodeQuest is a beginner-friendly Python learning environment built around short
game levels. Write real Python in the built-in editor, run it, compare your
output with the mission goal, reveal hints when you need them, and earn XP as
you unlock new concepts.

The first expedition introduces:

- `print()` and text output
- variables and number operations
- loops and conditionals
- lists, functions, and dictionaries

CodeQuest also includes personal practice tasks, saved code for every mission,
and local progress tracking.

## Installation

### Windows

1. Download the Windows ZIP.
2. Extract the entire `CodeQuest` folder.
3. Open the folder and run `CodeQuest.exe`.

Keep the `_internal` folder beside `CodeQuest.exe`; it contains the packaged
Python and Pygame runtime.

The initial free release is unsigned, so Windows may display a reputation
warning. Confirm that the file came from the official CodeQuest itch.io or
GitHub Release page and compare its published SHA-256 checksum.

## Controls

- Click an unlocked mission card to open it.
- Use **Run** to preview output and **Check** to submit.
- Press `Ctrl+Enter` to check from the keyboard.
- Press `Tab` for four spaces and `Ctrl+Z` to undo.
- Press `Escape` to return to the dashboard.

## Privacy

CodeQuest does not currently require an account, transmit learner code, or use
analytics. Progress is stored locally on the learner's computer. See the
included privacy notice for details.

## Current limitations

- Progress does not synchronize between computers.
- The first release is designed primarily for desktop keyboard and mouse use.
- Learner code runs with restricted built-ins and no imports; this is part of
  the puzzle environment.
