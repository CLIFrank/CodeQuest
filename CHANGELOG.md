# Changelog

## 1.0.0 - Initial desktop release

- Added eight progressive Python coding missions.
- Added an in-app editor with line numbers, syntax colors, indentation, undo,
  and clipboard paste.
- Added restricted learner-code execution with readable output and errors.
- Added hints, XP, quest unlocking, completion celebrations, and saved code.
- Added personal learner tasks and local JSON persistence.
- Added Windows, Linux, and macOS PyInstaller release automation.
