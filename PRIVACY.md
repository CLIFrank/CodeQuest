# CodeQuest privacy notice

CodeQuest 1.0 is an offline desktop application. It does not require an
account, display advertising, include analytics, or send learner code and
progress to a remote service.

The application stores the following information locally:

- completed mission identifiers;
- XP and streak values;
- learner-created task titles and completion state; and
- Python source entered for each mission.

The data is saved in the current user's home directory at:

```text
~/.codequest/progress.json
```

Deleting that file resets the local learner profile. Anyone with access to the
computer account may be able to read the saved task titles and source code, so
learners should not enter passwords or other sensitive information into tasks
or programs.

This notice applies to the offline 1.0 release. It must be updated before
adding accounts, cloud synchronization, analytics, or any network service.
